Instant Navigation in Next.js 16: A Practical Setup

Hey, it's Riz 👋 A misplaced Suspense boundary can silently block client-side navigation once Cache Components are on. This guide shows the setup that catches it at build time instead of in production.

The pattern 🧩

export const unstable_instant = { prefetch: 'static' }

export default async function Page({ params }) {
  return (
    <Suspense fallback={<p>Loading...</p>}>
      {params.then(({ slug }) => <Content slug={slug} />)}
    </Suspense>
  )
}

Why it matters ⚡

  • 📌 Validation simulates navigation from every shared layout boundary, not just the initial page load.
  • ✅ That's the failure mode that's easy to miss by hand.
