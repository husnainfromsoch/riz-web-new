Instant Navigation in Next.js 16: A Practical Setup

A note from me: with Cache Components enabled, a misplaced Suspense boundary can silently block client-side navigations. The unstable_instant export catches this at dev and build time instead of in production.

🧩 The pattern

export const unstable_instant = { prefetch: 'static' }

export default async function Page({ params }) {
  return (
    <Suspense fallback={<p>Loading...</p>}>
      {params.then(({ slug }) => <Content slug={slug} />)}
    </Suspense>
  )
}

⚡ Why it matters

Validation simulates navigation from every shared layout boundary, not just the initial page load — the failure mode that's easy to miss by hand.
