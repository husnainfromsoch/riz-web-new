Building Your First Agent with the Claude Agent SDK

An agent is a loop: give the model a goal, a set of tools, and let it decide what to call and when to stop.

The three things you actually need

A system prompt that states the goal and constraints, a small set of well-described tools, and a permission boundary for anything irreversible.

Start narrow

Ship an agent that does one task well before generalizing. Broad, vague tool access is where most early agents get stuck.
